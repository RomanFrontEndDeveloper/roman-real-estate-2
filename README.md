# 🏠 Roman Real Estate 2

Full Stack real estate platform built with modern web technologies.

## 🛠️ Tech Stack

- Next.js
- React
- TypeScript
- Node.js
- Express
- MongoDB
- Mongoose
- pnpm Workspace

## 🏗️ Project Structure

```text
roman-real-estate-2/
├── apps/
│   ├── client/    # Next.js frontend
│   └── server/    # Express backend
├── package.json
└── pnpm-workspace.yaml

🚀 Getting Started

Install dependencies:

pnpm install

Run frontend and backend together:

pnpm dev

Frontend:

http://localhost:3000

Backend:

http://localhost:5000
📌 Project Goal

The project is a practical Full Stack learning application focused on building a real estate platform from scratch.

Current stage:

Product Foundation → Client + Server → MongoDB + Mongoose

🚧 In Development
```
